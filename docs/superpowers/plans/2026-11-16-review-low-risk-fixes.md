## Review Focus

- Upsert under low heap: the user must see a memory message, not "rules full", and the HTTP status must be 503, not 409.
- `ack_all` under low heap: the response must not be `{"ok":true,"acked":0}`.
- `ack` with an engine that is not running: the response must be 503 `unavailable`, not 404.
- The Chiller PZEM log and notice must never say "pump 2" or "ปั๊ม 2".
- Rules-full must still return 409 `rules_full`, and the UI must still show the "มีกฎครบ" message.

These paths are not reachable in QEMU, because the engine needs FreeRTOS and NVS. Each one is pinned by a static contract check in `scripts/verify_alarm_system.py`, which follows the file's existing pattern of regex checks over the source.
