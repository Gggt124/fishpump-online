พิน GPIO ปัจจุบัน

GPIO 0 — Strapping Pin: ปุ่ม Factory Reset ใช้ GPIO 0 ซึ่งเป็น strapping pin ของ ESP32 ห้ามกดค้างขณะเปิดเครื่อง เพราะจะทำให้บอร์ดเข้า Download Mode แทนที่จะ boot ปกติ การกด Factory Reset จะลบข้อมูลทั้งหมด ได้แก่ Wi-Fi, รหัสผ่าน, การตั้งค่า Timer และ Hardware — เครื่องจะ Restart อัตโนมัติ หากต้องการความปลอดภัยมากขึ้น ให้ย้ายสาย Factory Reset ไปใช้ GPIO 14 แทน
คำแนะนำการเดินสาย (Wiring Guide)
  • ข้อควรระวังเรื่องระดับไฟ (ห้าม GPIO รับไฟเกิน 3.3V): ขา GPIO ของ ESP32 เมื่อทำหน้าที่เป็นขารับสัญญาณ (Input) จะรับไฟได้สูงสุดเพียง 3.3V (Not 5V-tolerant) หากนำเซนเซอร์ที่ส่งสัญญาณออกเป็น 5V มาต่อตรง ๆ ชิปจะเสียหาย ต้องใช้ Voltage Divider หรือ Level Shifter ส่วนขาที่ทำหน้าที่ ส่งสัญญาณ (Output) เช่น สั่งงานโมดูลรีเลย์ 5V การส่งลอจิก 3.3V ออกไปทริกสามารถทำได้ปกติ (แต่ควรใช้โมดูลรีเลย์แบบมี Optocoupler เพื่อป้องกันไฟ 5V ย้อนกลับ)
  • สวิตช์ลูกลอยและปุ่มกด (Mechanical Switches):
    • ขา Input-only (GPIO 34-39): ต้องต่อ Pull-up ภายนอกเสมอ เนื่องจากไม่มีวงจรภายใน
    • ระยะสายสั้น (ไม่เกิน 2 เมตร): แนะนำต่อ Pull-up 4.7kΩ ภายนอกเพื่อสู้กับสัญญาณรบกวน
    • ระยะสายไกล (2 - 10 เมตร):
      • สายไฟทำตัวเสมือนเสาอากาศรับคลื่นรบกวน (EMI) หลีกเลี่ยงการใช้ Internal Pull-up เดี่ยวๆ
      • ใช้สาย Shielded หรือ Twisted Pair
      • ลดค่า Pull-up ภายนอกเหลือ 1kΩ - 2.2kΩ (ต่อระหว่างพินกับ 3.3V)
      • ต่อตัวเก็บประจุ (Ceramic Capacitor) 0.1μF คร่อมพินกับ GND ที่ฝั่งบอร์ดเพื่อกรองสัญญาณรบกวน
      • (หมายเหตุ: เฟิร์มแวร์มี Software Debounce 100ms รองรับหน้าสัมผัสเด้งแล้ว)
  • เซนเซอร์อุณหภูมิ DS18B20 (บัส 1-Wire):
    • ระยะสายสั้น (ทั่วไป): ต้องต่อตัวต้านทาน Pull-up 4.7kΩ ที่สาย Data เสมอตามมาตรฐาน
    • ระยะสายไกล (> 5 เมตร):
      • แนะนำให้ใช้สายสัญญาณแบบ Cat5e โดยพันคู่สาย DQ และ GND ร่วมกัน
      • ต่อตัวต้านทาน 100Ω - 150Ω อนุกรมกับสาย DQ (ใกล้ขา ESP32) เพื่อลดคลื่นสะท้อน
      • ปรับลดตัวต้านทาน Pull-up ภายนอก (ระยะ 5-10ม. ใช้ 3.3kΩ / ระยะ 10-20ม. ใช้ 2.2kΩ)
      • คำเตือน: ห้ามใช้ Pull-up ต่ำกว่า 1.5kΩ เพื่อรักษา Sink Current 4mA ป้องกันเซนเซอร์พัง
      • คำเตือน: ห้ามใช้ Capacitor กรองสัญญาณมาต่อคร่อมขา Data เด็ดขาด การสื่อสารจะล้มเหลว
