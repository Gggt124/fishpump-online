# ติดตั้งและอัปเดตบอร์ด

## บอร์ดใหม่ (ต่อสาย USB)

ใช้ `flash-package.zip` จาก GitHub Release แตกแล้ว:

1. เสียบสาย USB ที่ช่อง **COM (หรือ UART)** ของบอร์ด ไม่ใช่ช่อง USB
2. ดับเบิลคลิก `FLASH.bat` พิมพ์เลขพอร์ต COM เมื่อถูกถาม (มีพอร์ตเดียวกด Enter, `R` = สแกนใหม่)
3. สคริปต์ลบทั้งบอร์ดก่อน แล้วเขียน `firmware\factory.bin` ที่ address 0x0 (ค่าแฟลชตามที่ build กำหนด `keep`) เสร็จแล้วอ่าน MAC และแสดงชื่อ Wi-Fi `FishPump-Setup` กับรหัสผ่านของบอร์ดนั้น จดใส่ป้ายแล้วติดที่เครื่อง
4. หน้าเว็บ `http://192.168.4.1` ล็อกอิน `admin` (ระบบบังคับเปลี่ยนรหัสผ่านครั้งแรก)

ในชุดติดตั้งยังมี `ERASE_FLASH.bat` (ล้างทั้งบอร์ด พิมพ์ YES ยืนยัน) และ README ภาษาไทย/อังกฤษสำหรับลูกค้า

## ลืมรหัส Wi-Fi ของบอร์ด

ต่อ USB แล้วรัน `SHOW_PASSWORD.bat` ไม่ลบหรือเปลี่ยนอะไร รหัสไม่ปรากฏใน log หรือ API ใดๆ

วิธีคำนวณ (ต้องตรงกับ `wifi_manager_build_ap_password` ใน `firmware/components/wifi_manager/wifi_manager.c`): เอา MAC ของบอร์ดไบต์ที่ 2 ถึง 5 แต่ละไบต์ XOR กับ `0x5A` เขียนเป็นเลขฐานสิบหกตัวใหญ่ 8 ตัว สูตรอยู่ที่เดียวใน `firmware/scripts/customer/tools/ap_password.ps1` มีตัวตรวจ `show_ap_password.ps1 -SelfTest` และ `verify_release_pipeline.py` เช็กว่าสูตรในเฟิร์มแวร์กับสคริปต์ตรงกัน ถ้าจะเปลี่ยนสูตรต้องแก้ทั้งสองที่พร้อมกัน เอกสารนี้ไม่เก็บรหัสของบอร์ดใดไว้

## อัปเดตบอร์ดที่ติดตั้งแล้ว (ไม่ต้องต่อสาย)

อิมเมจใหม่ต้องพอดี slot ขนาด 0x380000 ไบต์

| ทาง | ไฟล์ | ขั้นตอน |
|---|---|---|
| หน้าเว็บของบอร์ด (`POST /api/ota`) | `fishpump-<ver>-<fp>.ota.bin` (เข้ารหัส) | เลือกไฟล์ที่ลายนิ้วมือ `<fp>` ตรงกับที่บอร์ดรายงาน เพดานไฟล์ = ขนาด slot + 16 ไบต์ IV (0x380010) เกินจะได้ 413 `file_too_large` |
| ThingsBoard OTA | `fishpump-<ver>.bin` (ธรรมดา) | อัปโหลดเป็น package `fishpump` เวอร์ชันต่างจากที่รัน ดู `thingsboard/README.md` และ `docs/firmware/device-api.md` หัวข้อ 12 |

สองทางรับไฟล์คนละรูปแบบ อย่าเอา `.ota.bin` ไปอัปโหลดใน ThingsBoard หรือไฟล์ธรรมดาไปอัปโหลดทางเว็บ

ถ้า web OTA ปฏิเสธ (`invalid_ota_key` หรือบูตไม่ขึ้นใหม่) ตรวจลายนิ้วมือคีย์ก่อน ดู [`keys.md`](keys.md)
