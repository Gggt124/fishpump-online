# คู่มือทดสอบบนบอร์ด: ระบบป้องกันปั๊มเดินแห้ง (Dry-run protection)

Firmware: branch `feature/alarm-rules` (commit `8e7cabc`..`3a38f1a`)
Spec: `docs/superpowers/specs/2026-11-16-pump-dry-run-protection-design.md`
Plan: `docs/superpowers/plans/2026-11-16-pump-dry-run-protection.md`
ผลการทำงานของฝั่งโค้ด: `docs/superpowers/results/2026-11-16-pump-dry-run-protection-results.md`

> เปิดไฟล์นี้ไว้ก่อนต่อ Wi-Fi ของบอร์ด เพราะตอนต่อแล้ว PC จะไม่มีอินเทอร์เน็ต
> log ดูได้ที่พอร์ต **USB (COM12)** ด้วย `idf.py -C firmware -p COM12 monitor` ไม่ใช่พอร์ต UART
> ทุกข้อทำได้ **โดยไม่ต้องต่อเซนเซอร์หรือปั๊มจริง** จำลอง flow switch ด้วยสายจัมเปอร์ **GPIO 9 → GND**
> (ต่อจัมเปอร์ = "ไหล", ถอดจัมเปอร์ = "ไม่ไหล") ถ้ามีหลอดไฟ/โหลดเล็กต่อกับรีเลย์ 1 จะเห็นการทำงานชัดขึ้น
> สถานะ: `[ ]` ยังไม่ทำ · `[/]` ผ่าน · `[x]` ไม่ผ่าน (จดอาการในบรรทัด "บันทึก")

ศัพท์ที่ใช้: **WAIT** = ปั๊มถูกตัดและกำลังรอลองใหม่ · **LOCKED** = ปั๊มถูกล็อกจนกดรับทราบ ·
**MONITOR** = เฝ้าดูตามปกติ · **ผ่อนผัน (`prime_sec`)** = เวลาหลังรีเลย์เปิดที่ยังไม่นับว่าน้ำไม่ไหล ·
**`dry_trip_sec`** = เวลาที่น้ำไม่ไหลสะสมแล้วถือว่าเดินแห้ง

**ตำแหน่งการ์ดตั้งค่า:** หน้า **แผงควบคุม** → ส่วนตั้งค่า → เลื่อนลงหาการ์ดพับได้ **"การป้องกันปั๊มเดินแห้ง"** (อยู่ใต้การ์ดตั้งค่าปั๊ม) กดเพื่อกางออก
**ตำแหน่งตั้งเวลาปั๊ม:** การ์ดตั้งค่าปั๊มเดียวกัน แท็บ **Set 1 / Set 2** (ใช้ชุดที่ขึ้น `ACTIVE`) ช่อง "เปิด" และ "ปิด" ของปั๊มน้ำ

## 2. ปุ่ม "วัดให้" (Measure)

ปั๊มน้ำต้อง **หยุดอยู่** ก่อนกดวัด

1. **ทำ:** (ถอดจัมเปอร์) กด **"วัดให้"** ในการ์ด
   **ต้องเห็น:** หน้าต่างยืนยัน **"ปั๊มอาจเดินแห้งได้นานสุด 120 วินาทีระหว่างวัด ดำเนินการต่อ?"** กดตกลง แล้วขึ้น **"กำลังวัด... N วินาที"** พร้อมปุ่ม **"หยุดวัด"** รีเลย์ 1 เปิด
   รอจนครบ **120 วินาที** รีเลย์ปิดเอง และขึ้น **"ไม่พบน้ำไหลใน 120 วินาที ตรวจ flow switch / การล่อน้ำ"**
   และ **ไม่มี** แจ้งเตือนเดินแห้งเกิดขึ้น (การวัดหยุดระบบป้องกันชั่วคราว) และไม่มีค่าถูกบันทึกลงช่อง
   - [ ] ผ่าน  บันทึก: ______________________
2. **ทำ:** กด **"วัดให้"** อีกครั้ง (ถอดจัมเปอร์ไว้) รอประมาณ 10 วินาทีแล้ว **ต่อจัมเปอร์ GPIO 9–GND**
   **ต้องเห็น:** ขึ้น **"น้ำมาถึงใน N วินาที แนะนำช่วงผ่อนผัน M วินาที"** (N ≈ เวลาที่ต่อจัมเปอร์ + 1 วินาที debounce; M = ปัดขึ้น(N × 1.5) + 5) รีเลย์ปิด
   - [ ] ผ่าน  บันทึก: N=____ M=____
3. **ทำ:** กดปุ่ม **"ใช้ค่านี้"**
   **ต้องเห็น:** ช่อง **"ช่วงผ่อนผันหลังปั๊มเปิด (วินาที)"** เปลี่ยนเป็นค่า M (ยังไม่ถูกบันทึกจนกด "บันทึก")
   - [ ] ผ่าน  บันทึก: ______________________
4. **ทำ (เสริม):** กดวัดอีกครั้งแล้วกด **"หยุดวัด"** กลางคัน
   **ต้องเห็น:** ขึ้น "หยุดวัดแล้ว" รีเลย์ปิดทันที
   - [ ] ผ่าน  บันทึก: ______________________

## 3. ตั้งค่าให้ตัดเร็ว แล้วดูปั๊มถูกตัดรอบแรก

1. **ทำ:** ตั้งเวลาปั๊มน้ำ (ชุดที่ ACTIVE) เป็น **เปิด 20 วินาที / ปิด 60 วินาที** แล้วบันทึกการตั้งค่าปั๊ม
2. **ทำ:** ในการ์ดป้องกัน ตั้ง **ผ่อนผัน 5**, **เวลาไม่มีน้ำสะสมก่อนตัด 10**, **รอก่อนลองใหม่ 5 (นาที)**, **ลองใหม่สูงสุด 3**, เปิดสวิตช์การป้องกัน → **บันทึก**
   **ต้องเห็น:** toast "บันทึกการป้องกันแล้ว" สถานะเปลี่ยนเป็น **"เฝ้าดูอยู่"** log: `dry-run settings saved, protection on`
   - [ ] ผ่าน  บันทึก: ______________________
3. **ทำ:** (ถอดจัมเปอร์) กด start ปั๊มน้ำ แล้วจับเวลา
   **ต้องเห็น:** ที่ประมาณ **15 วินาที** (5 + 10) นับจากรีเลย์เปิด ใน **ช่วงเปิดรอบแรก** (ก่อนครบ 20 วินาที):
   - ปั๊ม (รีเลย์ 1) **ตัด** และไม่เปิดรอบถัดไปจนกว่าจะลองใหม่
   - LED **กระพริบแดง**
   - หน้า **แจ้งเตือน** มี **"ปั๊มน้ำเดินแห้ง" (วิกฤต)** พร้อมข้อความ **"หยุดปั๊ม ลองใหม่ใน mm:ss (ครั้งที่ 1/3)"** (ตัวเลขนับถอยหลัง)
   - log: `dry-run trip 1/3, pump stopped, retry in 300 s`
   - [ ] ผ่าน  บันทึก: ______________________
4. **ทำ (ระหว่างนี้):** เปิดแดชบอร์ดค้างไว้ (เพื่อให้ SSE ทำงาน) แล้วดู log ต่อ
   **ต้องเห็น:** บอร์ด **ไม่รีบูต** (ไม่มี boot log ใหม่ / uptime ในหน้าสถานะระบบไม่รีเซ็ต) ดูรายละเอียดข้อ 11

## 11. Stack ของ task `dry_run_guard` (4096 ไบต์)

## คำสั่ง API (ไม่บังคับ — ใช้ได้ใน Windows PowerShell 7 ตามนี้)

ระบบยืนยันตัวตนด้วย **คุกกี้ `session`** ที่ได้จาก `POST /api/login` และทุก POST ต้องมีหัว `Origin: http://192.168.4.1` (ตรงกับที่อยู่บอร์ด) ใน PowerShell ห้ามใช้ `curl` เฉยๆ (มันคือ alias ของ Invoke-WebRequest) ให้ใช้คำสั่งด้านล่าง ซึ่งเก็บคุกกี้ไว้ใน `$s` ให้เอง ทำจากเครื่องที่ต่อ Wi-Fi ของบอร์ดอยู่

**login (ทำครั้งเดียวต่อหน้าต่าง PowerShell)**

```powershell
$pw = Read-Host 'รหัสผ่าน admin'
$h = @{ Origin = 'http://192.168.4.1' }
$body = @{ username = 'admin'; password = $pw } | ConvertTo-Json -Compress
Invoke-RestMethod -Uri http://192.168.4.1/api/login -Method Post -ContentType 'application/json' -Headers $h -Body $body -SessionVariable s
```

ต้องได้ `ok : True` (ถ้าได้ `force_password_change` ให้เปลี่ยนรหัสผ่านที่หน้าเว็บก่อน)

**A. สั่ง start ตอน WAIT/LOCKED ต้องถูกปฏิเสธ `409`**

```powershell
$r = Invoke-WebRequest -Uri http://192.168.4.1/api/pump/start -Method Post -Headers $h -WebSession $s -SkipHttpErrorCheck
$r.StatusCode
$r.Content
```

ต้องได้ `409` และ `"error":"dry_run_waiting"` (ตอน WAIT พร้อม `wait_remaining_sec`) หรือ `"error":"dry_run_locked"` (ตอน LOCKED)

**B. ดูสถานะการป้องกันและสถานะปั๊ม**

```powershell
Invoke-RestMethod -Uri http://192.168.4.1/api/protection -WebSession $s | ConvertTo-Json -Depth 5
(Invoke-RestMethod -Uri http://192.168.4.1/api/pump/status -WebSession $s).dry_run
```

ต้องเห็น `state` (`disabled` / `monitor` / `wait` / `locked`), `trips`, `max_retries`, `wait_remaining_sec`, `dry_accum_sec`

**C. ส่งค่าผิดต้องได้ `400` พร้อมชื่อช่อง**

```powershell
$bad = '{"pump":{"enabled":true,"prime_sec":0,"dry_trip_sec":10,"retry_wait_min":5,"retry_backoff":true,"max_retries":3}}'
$r = Invoke-WebRequest -Uri http://192.168.4.1/api/protection -Method Post -ContentType 'application/json' -Headers $h -Body $bad -WebSession $s -SkipHttpErrorCheck
$r.StatusCode; $r.Content
```

ต้องได้ `400` และ `"message":"prime_sec"`
