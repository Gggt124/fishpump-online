### A2. ป้องกันเดินแห้ง: น้ำกลับมาไหลระหว่างรอลองใหม่

ใช้จัมเปอร์ GPIO 9–GND แทน flow switch (ต่อ = น้ำไหล, ถอด = ไม่ไหล) รอบก่อนเสียบจัมเปอร์ช้าเกินเวลารอ บอร์ดจึงลองใหม่จนล็อก (ได้ยืนยัน backoff 60/120/240 วินาทีและการล็อกแทน)

1. ถ้าการ์ดป้องกันยังล็อกหรือรออยู่ ให้กดรับทราบที่หน้าแจ้งเตือนจนการ์ดขึ้น **"เฝ้าดูอยู่"** แล้วตั้ง **ลองใหม่สูงสุด 3** และ **รอก่อนลองใหม่ 1 นาที** → บันทึก
2. ถอดจัมเปอร์ แล้ว start ปั๊มน้ำ
   **ต้องเห็น:** ตัดที่ประมาณ 15 วินาที เข้ารอ "ครั้งที่ 1/3" (log `dry-run trip 1/3, pump stopped, retry in 60 s`)
3. **ต่อจัมเปอร์ภายใน 1 นาทีนั้น** แล้วรอจนปั๊มเริ่มลองใหม่
   **ต้องเห็น:** หลังปั๊มเปิดและเห็นน้ำไหลต่อเนื่องประมาณ 5 วินาที แจ้งเตือน "ปั๊มน้ำเดินแห้ง" หาย (ประวัติมีแถว "หาย") LED หยุดแดง การ์ดกลับเป็น "เฝ้าดูอยู่" ปั๊มเดินตามตารางปกติ

## ส่วน B: ต้องต่อเซนเซอร์หรืออุปกรณ์จริง

### การต่อสาย

| UART | ESP32 TX | ESP32 RX | อุปกรณ์ |
|---|---|---|---|
| UART0 | GPIO 4 | GPIO 42 | PZEM-004T ของปั๊มน้ำ (รีเลย์ 1) |
| UART1 | GPIO 40 | GPIO 41 | PZEM-004T ของ Chiller |
| UART2 | GPIO 21 | GPIO 14 | RS485_TTL → SEN0708 (pH) |

**SEN0708 / RS485_TTL:**
- โมดูล RS485_TTL ต้องใช้ **VCC 3.3 V ห้ามใช้ 5 V** เพราะ GPIO 14 ทน 5 V ไม่ได้
- TXD → GPIO 14, RXD → GPIO 21
- A → สายเหลืองของ SEN0708, B → สายเส้นที่ 4, ⏚ → สายดำของ SEN0708 และ 0 V ของแหล่งจ่าย 12 V
- สายน้ำตาลของ SEN0708 ต่อ +12 V (ใช้ได้ 10–30 V)
- ถ้าเซนเซอร์ไม่ตอบ ลองสลับ TXD/RXD ก่อน แล้วค่อยลองสลับ A/B

### B1. PZEM-004T (ปั๊มน้ำ และ Chiller)
- [ ] ต่อเสร็จแล้ว ภายในประมาณ 2 วินาทีแถบแดงของการ์ดนั้นหายไป ตัวเลขขึ้นเป็นค่าปกติ (ไม่จาง)
- [ ] เปิดปั๊มน้ำอย่างเดียว: กระแสขึ้นที่การ์ดปั๊มน้ำ ส่วน Chiller ใกล้ 0 (ถ้าขึ้นผิดการ์ด แปลว่าสลับสาย UART0 กับ UART1)
- [ ] เปิด Chiller อย่างเดียว: ผลกลับกัน
- [ ] ค่า V ประมาณ 220–230, Hz ประมาณ 50, PF อยู่ในช่วง 0–1
- [ ] ถอดสาย PZEM ของ Chiller: **เฉพาะการ์ด Chiller** ขึ้นแดงภายในประมาณ 6 วินาที เสียบกลับแล้วหาย
- [ ] กด "รีเซ็ต kWh" → ยืนยัน → ค่า kWh กลับเป็น 0

### B2. SEN0708 (pH)
- [ ] แถบแดงหายไป ค่า pH และอุณหภูมิน้ำขึ้นเป็นค่าที่สมเหตุสมผล
- [ ] จุ่มในน้ำนิ่งๆ badge เปลี่ยนเป็น **"ค่านิ่ง"** ภายในประมาณ 10 วินาที และปุ่มคาลิเบรตกดได้
- [ ] ต้องโดนปฏิเสธ (ข้อความขึ้นใต้การ์ดคาลิเบรต):
  - [ ] กด "บันทึกจุดที่ 2" ก่อนจุดที่ 1 → "ต้องทำจุดที่ 1 ก่อน"
  - [ ] ใส่ 6.86 ในช่องจุดที่ 1 → "ค่าน้ำยาบัฟเฟอร์อยู่นอกช่วงของจุดนี้"
  - [ ] ขณะขยับหัววัด (badge "กำลังนิ่ง...") ปุ่มต้องกดไม่ได้
- [ ] คาลิเบรตจริง:
  1. [ ] น้ำยา pH 4.01 → รอนิ่ง → "บันทึกจุดที่ 1" → สถานะ "รอจุดที่ 2"
  2. [ ] ล้างหัววัด → น้ำยา pH 9.18 → รอนิ่ง → "บันทึกจุดที่ 2" → สถานะ "คาลิเบรตเสร็จ"
  3. [ ] จุ่มน้ำยา pH 6.86 → อ่านได้ราว 6.86 ±0.05
- [ ] Offset: ตั้ง +0.10 → ค่า pH ขยับขึ้นประมาณ 0.10 → "รีเซ็ตเป็น 0" → ค่ากลับเหมือนเดิม
- [ ] ถอดสาย A/B → ภายในประมาณ 6 วินาทีขึ้นแถบแดง เสียบกลับแล้วหาย

### B3. จูน preset แจ้งเตือนด้วยค่าจริง
- [ ] วัดกระแสปั๊มน้ำตอนทำงานจริง แล้วปรับ preset **"ปั๊มน้ำไม่ทำงานตามคำสั่ง"** (ตอนนี้ < 0.3 A ชั่วคราว)
- [ ] วัดกำลังไฟ Chiller ตอน standby และตอนทำงาน แล้วปรับ **"Chiller ไม่ทำงานตามคำสั่ง"** (< 50 W) และ **"Chiller ทำงานทั้งที่สั่งหยุด"** (> 200 W)
- [ ] ปิดเบรกเกอร์ Chiller แล้วดูว่า PZEM ตัวไหนหยุดตอบ (เพื่อรู้ว่ากฎ "มิเตอร์ไฟ Chiller ไม่ตอบ" ใช้ตรวจไฟดับได้ไหม)
- [ ] เพิ่มกฎ "กระแสปั๊มสูงเกิน" หลังรู้กระแสพิกัดของปั๊ม (ยังไม่มี preset)
- [ ] pH ออกนอกช่วงจริง (จุ่มน้ำยาบัฟเฟอร์): กฎ "pH ผิดช่วง" ขึ้นและหายตามเกณฑ์และช่วงกันสั่น
- [ ] รีเลย์ปั๊มน้ำค้าง: สั่งปิดรีเลย์ 1 แต่ปั๊มยังกินกระแส → กฎ "รีเลย์ปั๊มน้ำค้าง" ขึ้นแบบค้างรอรับทราบ (วิกฤต)

### B4. ปั๊มและท่อจริง
- [ ] ขั้วของ flow switch: NO ปิดวงจรเมื่อน้ำไหล (ถ้าใช้ NC ค่าจะกลับด้าน และเฟิร์มแวร์ยังไม่มีตัวเลือกกลับขั้ว)
- [ ] ปั๊มจริงกับ flow switch จริงในท่อ: ล่อน้ำแล้วกด "วัดให้" ได้ค่าสมเหตุสมผล ดึงท่อดูดขึ้นแล้วปั๊มถูกตัดตามเวลา
- [ ] จูนค่าป้องกันเดินแห้ง (`prime_sec`, `dry_trip_sec`, เวลารอลองใหม่) ตามเวลาล่อน้ำจริงของท่อ
- [ ] สวิตช์ลูกลอย (ต้องมีฮาร์ดแวร์)
- สังเกตจาก log เท่านั้น: ถ้าเห็น `Relay-1 test exceeded 130000 ms cap, switching relay 1 off` ระหว่างใช้งานจริง แปลว่าตัวควบคุมการวัดค้าง ให้แจ้ง (กระตุ้นจากหน้าเว็บไม่ได้ เพราะการวัดหยุดเองที่ 120 วินาที)
